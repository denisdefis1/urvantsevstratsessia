# urvancev-ux

Оптимизация лендинга «Антикризисная стратегическая сессия» (Tilda) с упором на мобильную версию.

## Что внутри

```
css/urvancev.css   шрифт, мобильная типографика, абзацы, формы, нижняя панель
js/urvancev.js     неразрывные пробелы, абзацы, склейка лишних переносов, нижняя панель
README.md
```

## Что делает

| Задача | Как решено |
|---|---|
| Шрифт Montserrat, заголовки Bold | Подключение через Google Fonts, `font-family` для всей страницы, `font-weight: 700` для заголовков, 600 для жирного в тексте |
| Висячие предлоги | JS ставит неразрывный пробел после предлогов, союзов и частиц (в, на, с, и, не, по, для, при и т. д.) |
| Тире, числа, телефон | Неразрывный пробел перед тире, внутри «230 000 ₽», «90 дней», «+7 903 530 58 94», «А.Н. Радчук», «ООО «Лаконд»» |
| Одинокое слово в конце абзаца | Последние два слова блока не разрываются; в CSS добавлены `text-wrap: pretty` и `balance` |
| Ручные переносы | Одиночный `<br>` посреди предложения («выходите / с планом») заменяется пробелом |
| Абзацы | Двойные `<br>` превращаются в `<p class="u-p">` с одинаковым отступом; жирный заход абзаца («Кризис называем вслух.») выводится отдельной строкой |
| Мобильный текст | 16 px, межстрочный 1.6, адаптивные заголовки через `clamp()` |
| Формы | Поля 16 px (iOS не зумит страницу), высота 48 px, `autocomplete` для имени и компании |
| Конверсия на телефоне | Нижняя панель «Обсудить ситуацию →» + кнопка звонка. Появляется после первого экрана, исчезает у формы и при открытой клавиатуре. Цвет берётся с вашей кнопки заявки |
| Якоря | Заголовок не прячется под фиксированным меню |
| Доступность | `alt` у картинок без подписи, `prefers-reduced-motion`, `lang="ru"` |

## Подключение

1. Создайте репозиторий на GitHub, загрузите папки `css` и `js`, сделайте релиз (тег), например `v1.0.0`.
2. В Tilda: **Настройки сайта → Ещё → HTML-код для вставки внутрь HEAD** (или для одной страницы: **Настройки страницы → Ещё**):

```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;600;700&display=swap" rel="stylesheet">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ@v1.0.0/css/urvancev.css">
```

3. Скрипт — в поле для вставки перед `</body>` либо в блок **T123 «HTML»** в самом низу страницы:

```html
<script defer src="https://cdn.jsdelivr.net/gh/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ@v1.0.0/js/urvancev.js"></script>
```

4. Опубликуйте страницу.

Всегда указывайте тег (`@v1.0.0`), а не `@main`: jsDelivr кеширует ветки до суток. При обновлении создавайте новый тег и меняйте его в ссылках.
Свой HTML-код в Tilda работает на платном тарифе.

## Настройки

В начале `js/urvancev.js` есть объект `CONFIG`: текст кнопки, телефон, якорь формы, ширина экрана для панели, подписи картинок. В `:root` файла `css/urvancev.css` — отступ между абзацами, радиус кнопки, запасной цвет панели.

Отключить обработку текста в блоке: добавьте атрибут `data-no-typo` на родительский элемент.
Оставить конкретный перенос строки: добавьте `data-keep` на тег `<br>`.

## Проверка после публикации

- iPhone SE (320 px) и Android 360 px: нет горизонтальной прокрутки, нет строк, заканчивающихся предлогом.
- Нижняя панель: не появляется на первом экране, пропадает у формы, не перекрывает кнопку «Отправить заявку».
- Нажатие на пункты меню и якоря: заголовок раздела виден целиком.
- Форма: на iPhone страница не увеличивается при фокусе на поле.
- Консоль браузера: `UrvancevUX.typo('в доме')` возвращает строку с неразрывным пробелом.

## Ограничения

- Селекторы рассчитаны на стандартные классы Tilda (`.t-text`, `.t-descr`, `.t-title`, `.t-heading`, `.t-input`, `.t-btn`). Блоки, собранные в Zero Block (`.tn-atom`), получают шрифт и неразрывные пробелы, но не размеры и отступы: там они задаются вручную по брейкпоинтам в редакторе. Если после публикации какой-то блок выглядит не так, пришлите его HTML (DevTools → Copy outerHTML), и я поправлю селекторы.
- Шрифт грузится с Google Fonts. Если важна работа без внешних серверов, скачайте Montserrat (400, 500, 600, 700, cyrillic) и подключите через `@font-face` из репозитория.
- Код не меняет содержание страницы. Смысловые правки (кейс именно по антикризисной сессии, пример плана на 90 дней, границы услуги, экономика бездействия) делаются в тексте.
